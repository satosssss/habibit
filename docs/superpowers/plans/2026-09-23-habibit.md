# Habibit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Habibit, a local-only habit tracker that reproduces the Grit app's UX (Today / Timer / Stats / Note view / Settings) as a responsive Next.js App Router app persisted entirely in Dexie/IndexedDB.

**Architecture:** App Router routes (`/today`, `/today/[date]`, `/stats`, `/settings`) share a `NavShell` layout whose nav changes shape at breakpoints (bottom tab bar → 72px icon rail → 240px sidebar). All reads go through `useLiveQuery` over `src/lib/repo.ts`, which is the only module that touches Dexie; pure logic (dates, stats, seeding) lives in dependency-free modules so it can be unit-tested without a DOM.

**Tech Stack:** Next.js 15 (App Router, TypeScript), Tailwind CSS v4, Dexie 4 (IndexedDB, `liveQuery`), lucide-react (bundled icons), Vitest + jsdom + Testing Library, fake-indexeddb (test double **and** runtime fallback when IndexedDB is unavailable).

**Spec:** `docs/superpowers/specs/2026-09-23-habibit-design.md` — this plan argues from the spec; executors must read both.

## Global Constraints

- Next.js App Router + Tailwind CSS; deploys to Vercel with zero config beyond `vercel deploy`.
- Dexie over IndexedDB only. No backend, no database service, no auth, no analytics, no third-party API or CDN (no external fonts or icons — lucide-react ships in the bundle).
- Components never import `dexie` directly; all persistence flows through `src/lib/repo.ts` (except `src/lib/useLiveQuery.ts`, which imports `liveQuery`).
- `category` (time/context: Morning, Health, Evening) and `intention` (meaning/purpose: Study, Do Hard Things, …) are **two separate fields and must never be merged**.
- Today groups sections by `category` **only**. Stats and the quote/note view group and color-code by `intention`.
- `frequency` is `number[]` of weekday indices, 0 (Sunday) – 6 (Saturday).
- A day is **active** if ≥1 scheduled habit was completed; a **perfect day** is when every scheduled habit was completed. Per-habit flame = consecutive scheduled-and-completed days.
- Date strip is exactly **7 columns = 5 previous days + today + 1 disabled future preview**.
- Heatmap is a **true GitHub grid**: 7 weekday rows (Mon–Sun) × week columns, single-hue 5-level intensity, month labels on top, weekday labels on the left, `Less ▢▢▢▢▢ More` legend, hover/tap tooltip showing date, `completed of scheduled`, and percentage.
- Seed = 8 example habits **plus ~13 weeks of backdated entries** from a seeded PRNG; identical history on every fresh install.
- No `useEffect` that syncs date or route state; exactly one `setInterval` exists in the app (the timer) and it is always cleared on unmount.
- Three real responsive layouts at 390 / 768–1024 / 1280+ — no `window.innerWidth`, no JS resize listeners; Tailwind breakpoints + CSS columns only.
- Cross-platform: identical dev on Windows and Mac. Only `npm run …` scripts and forward-slash paths in tooling config (`fileURLToPath`, never string-concatenated paths).

### Plan-level decisions not pinned by the spec (flagged for the reviewer)

1. **`unit: string` added to `Habit`.** The screenshots' subtexts (`4/8 cups`, `784/1,000 calories`, `30 minutes/45 minutes`) cannot render without a unit. Spec §4.2 omitted it; the schema gains `unit` (empty for `boolean` and `timer`, where minutes/seconds derive from `target`).
2. **Intention color and category icon are derived, not stored.** Spec keeps two tables, so `intentionColor(name)` hashes the intention name into a fixed subtle palette (stable everywhere it appears), `categoryIcon(name)` maps `morning→Sunrise`, `health→Heart`, `evening→Moon` with a hash fallback, and `intentionIcon(habits, intention)` uses the first matching habit's icon. No schema change, no drift.
3. **Row fill floor.** White text must stay readable, so `boolean` rows render fully saturated (the check carries state) and `quantity`/`timer` rows render `max(0.55, ratio)` as the saturated width. Authoritative progress stays in the ring, the stepper, and the `x/y` subtext — all screenshots show rows ≥50% filled, so this matches the reference rather than deviating from it.
4. **Seed intentions** are `Do Hard Things`, `Avoid Traps`, `Study`, `Be Grateful` — the screenshot's four, with the spec's own example `Study` included.

## Review Focus

Inputs/conditions the spec implies that no single happy-path task exercises. Each line is pinned by a test in the named task.

1. **Local date keys must never shift a day** (the classic `new Date('2026-03-08')` UTC-parse bug, and DST boundaries) → Task 2, `toKey/fromKey round-trip` + `addDays across a DST boundary`.
2. **Timer interval must not survive unmount** (background tab / modal closed mid-run) → Task 9, `clears the interval on unmount`.
3. **Streak must not break on a day with zero scheduled habits, and must not break on a not-yet-complete today** → Task 5, `skips days with no scheduled habits` + `does not break on an incomplete today`.
4. **Re-seeding must be idempotent** — reload, or delete-all-habits-then-reload, must never duplicate entries or resurrect user data → Task 4, `seeds exactly once` + `does not re-seed after habits are deleted`.
5. **Future-dated entries** (reachable via imported JSON or a future route param) must not count in stats and must not be checkable → Task 5, `ignores future-dated entries`; Task 12, `future date redirects to /today`.
6. **Heatmap year boundaries** — partial weeks at Jan 1 / Dec 31 must not shift later columns → Task 11, `emits exactly the days of the year, padded to whole weeks`.
7. **Import must be atomic** — malformed JSON must leave the existing data untouched → Task 14, `rejects malformed payload without touching stored data`.

```tsx
  { href: '/today', label: 'Today', Icon: CalendarCheck },

      : 'text-[var(--color-subtle)] hover:bg-[var(--color-muted)] hover:text-[var(--color-fg)]',

          <Link key={href} href={href} aria-current={isActive(href) ? 'page' : undefined}
                className={linkClass(isActive(href))} title={label}>
            <Icon size={20} />

        ))}
      </nav>

      <div className="min-w-0 flex-1 pb-24 md:pb-0">{children}</div>

      {/* Mobile bottom tab bar */}
```

```ts
// src/lib/dates.ts
const KEY_RE = /^\d{4}-\d{2}-\d{2}$/;

export function isValidDateKey(key: string): boolean {
  if (!KEY_RE.test(key)) return false;
  const d = fromKey(key);
  return !Number.isNaN(d.getTime()) && toKey(d) === key;
}

/** Local-time ISO-day key. Never uses Date#toISOString, which shifts to UTC. */
export function toKey(d: Date): string {
  const m = String(d.getMonth() + 1).padStart(2, '0');
  const day = String(d.getDate()).padStart(2, '0');
  return `${d.getFullYear()}-${m}-${day}`;
}

export function fromKey(key: string): Date {
  const [y, m, d] = key.split('-').map(Number);
  return new Date(y, m - 1, d); // local midnight; 'YYYY-MM-DD' string parsing would be UTC
}

export function addDays(key: string, n: number): string {
  const d = fromKey(key);
  d.setDate(d.getDate() + n);
  return toKey(d);
}

export function todayKey(): string {
  return toKey(new Date());
}

export function weekdayIndex(key: string): number {
  return fromKey(key).getDay(); // 0 = Sunday … 6 = Saturday
}

export function dayOfYear(key: string): number {
  const d = fromKey(key);
  const start = new Date(d.getFullYear(), 0, 1);
  return Math.round((d.getTime() - start.getTime()) / 86_400_000) + 1;
}

/** Exactly 7 columns: 5 previous days, today, 1 disabled future preview. */
export function stripDays(anchor: string = todayKey()): string[] {
  return Array.from({ length: 7 }, (_, i) => addDays(anchor, i - 5));
}

export function formatLong(key: string): string {
  return fromKey(key).toLocaleDateString('en-US', {
    weekday: 'long', month: 'long', day: 'numeric',
  });
}

export function formatShort(key: string): string {
  return fromKey(key).toLocaleDateString('en-US', { month: 'short', day: 'numeric' });
}

export function formatWeekday(key: string): string {
  return fromKey(key).toLocaleDateString('en-US', { weekday: 'short' });
}

export function classifyDate(key: string, today: string = todayKey()): 'past' | 'today' | 'future' {
  if (key === today) return 'today';
  return key < today ? 'past' : 'future';
}

export function isLeapYear(year: number): boolean {
  return (year % 4 === 0 && year % 100 !== 0) || year % 400 === 0;
}

export function yearDays(year: number): string[] {
  const length = isLeapYear(year) ? 366 : 365;
  return Array.from({ length }, (_, i) => toKey(new Date(year, 0, 1 + i)));
}

/** Monday-based weekday position: Monday = 0 … Sunday = 6. */
function mondayIndex(key: string): number {
  return (weekdayIndex(key) + 6) % 7;
}

/** First day of the GitHub grid: the Monday on or before Jan 1. */
export function gridStart(year: number): string {
  return addDays(`${year}-01-01`, -mondayIndex(`${year}-01-01`));
}

/** 0-based week column containing the given date. */
export function weekColumn(key: string, year: number): number {
  const start = gridStart(year);
  const diff = Math.floor((fromKey(key).getTime() - fromKey(start).getTime()) / 86_400_000);
  return Math.floor(diff / 7);
}

  return Array.from({ length: 12 }, (_, month) => ({
    month,
    column: weekColumn(toKey(new Date(year, month, 1)), year),
  }));
}

  const last = `${year}-12-31`;
  return weekColumn(last, year) + 1;
```

```ts
import Dexie, { type Table } from 'dexie';
import type { Entry, Habit } from './types';

export class HabibitDexie extends Dexie {
  habits!: Table<Habit, string>;
  entries!: Table<Entry, string>;

  constructor(name = 'habibit') {
    super(name);
    this.version(1).stores({
      habits: 'id, name, category, intention, type, order, createdAt',
      entries: 'id, habitId, date, value, timestamp, [habitId+date]',
    });
  }

/** Live module binding — reassigned by ensureDb() if IndexedDB is unavailable. */
export let db = new HabibitDexie('habibit');

export type DbStatus = 'ok' | 'degraded';
let openPromise: Promise<DbStatus> | null = null;
let status: DbStatus | 'unknown' = 'unknown';

export function persistenceStatus(): DbStatus | 'unknown' {
  return status;
}

/**
 * Opens IndexedDB. When it is unavailable (private browsing, locked profile),
 * rewires Dexie onto fake-indexeddb and swaps in a fresh instance so the app
 * stays usable for the session; callers surface `degraded` as a warning banner.
 */
export function ensureDb(): Promise<DbStatus> {
  if (!openPromise) {
    openPromise = (async (): Promise<DbStatus> => {
      try {
        await db.open();
        status = 'ok';
        return 'ok';
      } catch {
        const fake = await import('fake-indexeddb');
        Dexie.dependencies.indexedDB = fake.indexedDB;
        Dexie.dependencies.IDBKeyRange = fake.IDBKeyRange;
        db = new HabibitDexie('habibit');
        try {
          await db.open();
          status = 'degraded';
        } catch {
          status = 'degraded';
        }
        return 'degraded';
      }
    })();
  }
  return openPromise;
}

export async function resetDb(): Promise<void> {
  await ensureDb();
  await db.habits.clear();
  await db.entries.clear();
}
```

```ts
import { db, ensureDb, resetDb } from './db';
import type { Entry, Habit } from './types';

export function newId(): string {
  return globalThis.crypto?.randomUUID?.() ?? `id-${Date.now()}-${Math.random().toString(36).slice(2)}`;
}

export async function listHabits(): Promise<Habit[]> {
  await ensureDb();
  return db.habits.toArray();
}

export async function countHabits(): Promise<number> {
  await ensureDb();
  return db.habits.count();
}

export async function putHabit(habit: Habit): Promise<Habit> {
  await ensureDb();
  await db.habits.put(habit);
  return habit;
}

export async function deleteHabit(id: string): Promise<void> {
  await ensureDb();
  await db.transaction('rw', db.habits, db.entries, async () => {
    await db.habits.delete(id);
    await db.entries.where('habitId').equals(id).delete();
  });
}

export async function loadDay(date: string): Promise<Entry[]> {
  await ensureDb();
  return db.entries.where('date').equals(date).toArray();
}

export async function loadRange(from: string, to: string): Promise<Entry[]> {
  await ensureDb();
  return db.entries.where('date').between(from, to, true, true).toArray();
}

export async function setMany(entries: Entry[]): Promise<void> {
  await ensureDb();
  await db.entries.bulkPut(entries);
}

export async function putEntry(habitId: string, date: string, value: number): Promise<Entry> {
  await ensureDb();
  const entry: Entry = { id: `${habitId}_${date}`, habitId, date, value, timestamp: Date.now() };
  await db.entries.put(entry);
  return entry;
}

export async function clearAll(): Promise<void> {
  await ensureDb();
  await resetDb();
}

/** Removes entries whose habit no longer exists (spec §12). Returns the count removed. */
export async function pruneOrphans(): Promise<number> {
  await ensureDb();
  const ids = new Set((await db.habits.toArray()).map((h) => h.id));
  const orphans = (await db.entries.toArray()).filter((e) => !ids.has(e.habitId));
  if (orphans.length) await db.entries.bulkDelete(orphans.map((e) => e.id));
  return orphans.length;
}

export async function exportState(): Promise<{ habits: Habit[]; entries: Entry[] }> {
  await ensureDb();
  return { habits: await db.habits.toArray(), entries: await db.entries.toArray() };
}

function isHabit(x: unknown): x is Habit {
  if (!x || typeof x !== 'object') return false;
  const h = x as Record<string, unknown>;
  return (
    typeof h.id === 'string' && typeof h.name === 'string' &&
    typeof h.category === 'string' && typeof h.intention === 'string' &&
    (h.type === 'boolean' || h.type === 'quantity' || h.type === 'timer') &&
    typeof h.target === 'number' && typeof h.unit === 'string' &&
    Array.isArray(h.frequency) && typeof h.order === 'number' &&
    typeof h.createdAt === 'number'
  );
}

function isEntry(x: unknown): x is Entry {
  if (!x || typeof x !== 'object') return false;
  const e = x as Record<string, unknown>;
  return (
    typeof e.id === 'string' && typeof e.habitId === 'string' &&
    typeof e.date === 'string' && typeof e.value === 'number' &&
    typeof e.timestamp === 'number'
  );
}

/** Validates fully before writing anything, so a bad file never half-applies. */
export async function importState(data: unknown): Promise<void> {
  const payload = data as { habits?: unknown; entries?: unknown } | null;
  const ok =
    !!payload && Array.isArray(payload.habits) && Array.isArray(payload.entries) &&
    payload.habits.every(isHabit) && payload.entries.every(isEntry);
  if (!ok) throw new Error("That file isn't a Habibit export.");
  await ensureDb();
  const habits = payload.habits as Habit[];
  const entries = payload.entries as Entry[];
  await db.transaction('rw', db.habits, db.entries, async () => {
    await db.habits.clear();
    await db.entries.clear();
    await db.habits.bulkPut(habits);
    await db.entries.bulkPut(entries);
  });
}
```

```tsx
// src/lib/useLiveQuery.ts
'use client';

import { liveQuery } from 'dexie';
import { useEffect, useMemo, useState, type DependencyList } from 'react';

/**
 * Subscribes to a Dexie liveQuery. `deps` must list every value the query
 * function closes over (e.g. `[date]` for a per-day query) — changing them
 * tears the subscription down and re-subscribes. There is deliberately no
 * effect that writes route/date state back into React.
 */
export function useLiveQuery<T>(fn: () => Promise<T>, deps: DependencyList): T | undefined {
  // eslint-disable-next-line react-hooks/exhaustive-deps
  const observable = useMemo(() => liveQuery(fn), deps);
  const [value, setValue] = useState<T | undefined>(undefined);

  useEffect(() => {
    let alive = true;
    const sub = observable.subscribe({
      next: (v) => { if (alive) setValue(v); },
      error: (err) => console.error('[habibit] liveQuery error', err),
    });
    return () => { alive = false; sub.unsubscribe(); };
  }, [observable]);

  return value;
}
```

/** mulberry32 — tiny deterministic PRNG so every fresh install seeds identically. */
function mulberry32(seed: number): () => number {
  let a = seed;
  return () => {
    a = (a + 0x6d2b79f5) | 0;
    let t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

function valueFor(habit: Habit, complete: boolean, rnd: () => number): number {
  if (habit.type === 'boolean') return complete ? 1 : 0;
  if (!complete) return Math.max(0, Math.floor(rnd() * habit.target * 0.6));
  return habit.target;
}

```ts
export function generateSeedEntries(habits: Habit[], anchorDate: string, weeks = 13): Entry[] {
  const rnd = mulberry32(20_260_923);
  const entries: Entry[] = [];
  const start = addDays(anchorDate, -(weeks * 7 - 1));
  const totalDays = weeks * 7;

  for (let i = 0; i < totalDays; i++) {
    const date = addDays(start, i);
    const scheduled = habits.filter((h) => h.frequency.includes(weekdayIndex(date)));
    if (scheduled.length === 0) continue;

    const recent = i >= totalDays - 8;   // keep the seeded current streak alive
    const perfect = rnd() < 0.12;        // ~12% perfect days

    let anyComplete = false;
    for (const habit of scheduled) {
      const complete = perfect ? true : recent ? rnd() < 0.85 : rnd() < 0.78;
      if (complete) anyComplete = true;
      entries.push({
        id: `${habit.id}_${date}`,
        habitId: habit.id,
        date,
        value: valueFor(habit, complete, rnd),
        timestamp: Date.parse(`${date}T09:00:00`),
      });
    }
    // A recent day must be active, or the seeded current streak reads 0.
    if (recent && !anyComplete) {
      const habit = scheduled[0];
      const idx = entries.findIndex((e) => e.id === `${habit.id}_${date}`);
      if (idx >= 0) entries[idx] = { ...entries[idx], value: valueFor(habit, true, rnd) };
    }
  }
  return entries;
}
```

```ts
// src/lib/stats.ts
import { addDays, gridStart, todayKey, weekColumn, weekdayIndex, yearDays } from './dates';
import type { Entry, Habit } from './types';

export interface DayStat {
  date: string;
  scheduled: number;
  completed: number;
  ratio: number;
  active: boolean;
  perfect: boolean;
}

export interface IntentionStat {
  intention: string;
  completed: number;
  scheduled: number;
}

export interface HeatCell {
  date: string;
  inYear: boolean;
  future: boolean;
  completed: number;
  scheduled: number;
  ratio: number;
  level: 0 | 1 | 2 | 3 | 4;
}

export function isCompleted(habit: Habit, value: number): boolean {
  if (habit.type === 'boolean') return value > 0;
  return value >= habit.target;
}

function isScheduled(habit: Habit, date: string): boolean {
  if (!habit.frequency.includes(weekdayIndex(date))) return false;
  const dayStart = Date.parse(`${date}T00:00:00`);
  return habit.createdAt <= dayStart + 86_399_999;
}

function dayStat(date: string, habits: Habit[], byDate: Map<string, Entry[]>): DayStat {
  const scheduled = habits.filter((h) => isScheduled(h, date));
  const entries = byDate.get(date) ?? [];
  const values = new Map(entries.map((e) => [e.habitId, e.value]));
  const completed = scheduled.filter((h) => isCompleted(h, values.get(h.id) ?? 0)).length;
  return {
    date,
    scheduled: scheduled.length,
    completed,
    ratio: scheduled.length ? completed / scheduled.length : 0,
    active: completed > 0,
    perfect: scheduled.length > 0 && completed === scheduled.length,
  };
}

function indexEntries(entries: Entry[]): Map<string, Entry[]> {
  const map = new Map<string, Entry[]>();
  for (const entry of entries) {
    const list = map.get(entry.date);
    if (list) list.push(entry);
    else map.set(entry.date, [entry]);
  }
  return map;
}

export function buildDayStats(
  habits: Habit[],
  entries: Entry[],
  opts: { from?: string; to?: string } = {},
): Map<string, DayStat> {
  const to = opts.to ?? todayKey();
  const from = opts.from ?? gridStart(Number(to.slice(0, 4)));
  const byDate = indexEntries(entries.filter((e) => e.date >= from && e.date <= to));
  const stats = new Map<string, DayStat>();
  let cursor = from;
  while (cursor <= to) {
    stats.set(cursor, dayStat(cursor, habits, byDate));
    cursor = nextDayShift(cursor, 1);
  }
  return stats;
}

function nextDayShift(key: string, delta: number): string {
  return addDays(key, delta);
}

const scheduledOnly = (stats: Map<string, DayStat>) =>
  [...stats.values()].filter((s) => s.scheduled > 0);

export function countActiveDays(stats: Map<string, DayStat>): number {
  return scheduledOnly(stats).filter((s) => s.active).length;
}

export function countPerfectDays(stats: Map<string, DayStat>): number {
  return scheduledOnly(stats).filter((s) => s.perfect).length;
}

export function sumCompletions(stats: Map<string, DayStat>): number {
  return scheduledOnly(stats).reduce((sum, s) => sum + s.completed, 0);
}

export function completionRate(stats: Map<string, DayStat>): {
  completed: number; scheduled: number; rate: number;
} {
  const days = scheduledOnly(stats);
  const completed = days.reduce((sum, s) => sum + s.completed, 0);
  const scheduled = days.reduce((sum, s) => sum + s.scheduled, 0);
  return { completed, scheduled, rate: scheduled ? completed / scheduled : 0 };
}

/**
 * Active-day streak walking back from `today`.
 * - Days with no scheduled habits are skipped: they neither count nor break.
 * - An incomplete `today` does not break yesterday's streak (the day isn't over).
 */
export function currentStreak(stats: Map<string, DayStat>, today: string): number {
  let streak = 0;
  let cursor: string | undefined = today;
  while (cursor && stats.has(cursor)) {
    const day = stats.get(cursor)!;
    if (day.scheduled === 0) { cursor = prevDay(cursor); continue; }  // neither counts nor breaks
    if (day.active) { streak++; cursor = prevDay(cursor); continue; }
    if (cursor === today) { cursor = prevDay(cursor); continue; }     // today isn't over yet
    break;                                                            // a missed day ends the run
  }
  return streak;
}

function prevDay(key: string): string {
  return nextDayShift(key, -1);
}

export function longestStreak(stats: Map<string, DayStat>): number {
  let best = 0;
  let run = 0;
  for (const day of [...stats.values()].sort((a, b) => a.date.localeCompare(b.date))) {
    if (day.scheduled === 0) continue;
    run = day.active ? run + 1 : 0;
    best = Math.max(best, run);
  }
  return best;
}

export function perIntentionTotals(
  habits: Habit[],
  entries: Entry[],
  year: number,
  today: string = todayKey(),
): IntentionStat[] {
  const from = `${year}-01-01`;
  const to = today < `${year}-12-31` ? today : `${year}-12-31`;
  const stats = buildDayStats(habits, entries, { from, to });
  const byDate = indexEntries(entries);
  const intentions = [...new Set(habits.map((h) => h.intention))];

  return intentions.map((intention) => {
    const members = habits.filter((h) => h.intention === intention);
    let completed = 0;
    let scheduled = 0;
    for (const [date, day] of stats) {
      const rows = new Map((byDate.get(date) ?? []).map((e) => [e.habitId, e.value]));
      for (const habit of members) {
        if (!isScheduled(habit, date)) continue;
        scheduled++;
        if (isCompleted(habit, rows.get(habit.id) ?? 0)) completed++;
      }
    }
    return { intention, completed, scheduled };
  });
}

const LEVEL_STEPS = 4;

export function levelFor(ratio: number, completed: number): 0 | 1 | 2 | 3 | 4 {
  if (completed <= 0 || ratio <= 0) return 0;
  return Math.min(LEVEL_STEPS, Math.ceil(ratio * LEVEL_STEPS)) as 1 | 2 | 3 | 4;
}

export function heatmapCells(
  year: number,
  habits: Habit[],
  entries: Entry[],
  today: string = todayKey(),
): HeatCell[] {
  const start = gridStart(year);
  const inYear = yearDays(year);
  const byDate = indexEntries(entries);
  // Whole weeks covering Jan 1 … Dec 31: the grid start is the Monday on or
  // before Jan 1, so the number of weeks is the column of Dec 31 plus one.
  const daysNeeded = (weekColumn(`${year}-12-31`, year) + 1) * 7;
  const cells: HeatCell[] = [];

  for (let i = 0; i < daysNeeded; i++) {
    const date = nextDayShift(start, i);
    const inYearDay = inYear.includes(date);
    const day = inYearDay ? dayStat(date, habits, byDate) : null;
    const future = date > today;
    cells.push({
      date,
      inYear: inYearDay,
      future,
      completed: day?.completed ?? 0,
      scheduled: day?.scheduled ?? 0,
      ratio: day?.ratio ?? 0,
      level: !day || future ? 0 : levelFor(day.ratio, day.completed),
    });
  }
  return cells;
}
```

```ts
// src/lib/hash.ts
/** Deterministic string → index. Avoids Object.hashCode and crypto (sync, no deps). */
export function stableIndex(str: string, length: number): number {
  let h = 5381;
  for (let i = 0; i < str.length; i++) h = ((h << 5) + h + str.charCodeAt(i)) | 0;
  return Math.abs(h) % length;
}
```

```ts
// src/lib/colors.ts
import { stableIndex } from './hash';

/** Bright, saturated fills for habit rows — the screenshot palette. */
export const HABIT_COLORS = [
  '#c026d3', '#22d3ee', '#3b82f6', '#6366f1', '#22c55e',
  '#ef4444', '#f97316', '#f59e0b', '#14b8a6', '#ec4899',
];

/** Deliberately subtle — intentions are groupings, not actions. No overlap with HABIT_COLORS. */
export const INTENTION_PALETTE = [
  '#f97316', '#eab308', '#14b8a6', '#38bdf8',
  '#a3e635', '#fb7185', '#818cf8', '#94a3b8',
];

export function rgba(hex: string, alpha: number): string {
  const value = hex.replace('#', '');
  const full = value.length === 3 ? value.split('').map((c) => c + c).join('') : value;
  if (!/^[0-9a-fA-F]{6}$/.test(full)) throw new Error(`Invalid color: ${hex}`);
  const n = parseInt(full, 16);
  return `rgba(${(n >> 16) & 255}, ${(n >> 8) & 255}, ${n & 255}, ${alpha})`;
}

/** Stable, memorable color for an intention name — same name, same color, everywhere. */
export function intentionColor(name: string): string {
  return INTENTION_PALETTE[stableIndex(name.trim().toLowerCase(), INTENTION_PALETTE.length)];
}
```

```ts
  timer: Timer, triangleAlert: TriangleAlert, wallet: Wallet, workout: Workout,
} satisfies Record<string, LucideIcon>;

export type IconName = keyof typeof ICONS;
export const ICON_CHOICES = Object.keys(ICONS) as IconName[];

export function nameIcon(name: string): LucideIcon {
  return ICONS[name as IconName] ?? PenLine;
}

const CATEGORY_MAP: Record<string, IconName> = {
  morning: 'sunrise', afternoon: 'sun', evening: 'moon', night: 'moon',
  health: 'heart', mind: 'brain', work: 'wallet', study: 'graduation',
};

export function categoryIcon(name: string): LucideIcon {
  const key = name.trim().toLowerCase();
  const mapped = CATEGORY_MAP[key];
  return nameIcon(mapped ?? ICON_CHOICES[stablePick(key)]);
}

function stablePick(str: string): number {
  let h = 5381;
  for (let i = 0; i < str.length; i++) h = ((h << 5) + h + str.charCodeAt(i)) | 0;
  return Math.abs(h) % ICON_CHOICES.length;
}

/** An intention borrows the icon of its first habit — no extra field, no drift. */
export function intentionIcon(habits: Habit[]): LucideIcon {
  return nameIcon(habits[0]?.icon ?? 'crown');
}
```

```ts
// src/lib/labels.ts
import type { Habit } from './types';

const DAY_NAMES = ['Sun', 'Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat'];

export function frequencyLabel(frequency: number[]): string {
  const sorted = [...frequency].sort((a, b) => a - b);
  if (sorted.length === 7) return 'Every day';
  if (sorted.join(',') === '1,2,3,4,5') return 'Weekdays';
  if (sorted.join(',') === '0,6') return 'Weekends';
  return sorted.map((d) => DAY_NAMES[d]).join(', ');
}

function minutes(seconds: number): string {
  const m = Math.round(seconds / 60);
  return `${m} ${m === 1 ? 'minute' : 'minutes'}`;
}

/** Exactly the screenshot's subtexts: "Every day, 4/8 cups" / "Every day, 10 minutes/15 minutes". */
export function subtext(habit: Habit, value: number): string {
  const freq = frequencyLabel(habit.frequency);
  if (habit.type === 'quantity') return `${freq}, ${value}/${habit.target} ${habit.unit}`.trimEnd();
  if (habit.type === 'timer') return `${freq}, ${minutes(value)}/${minutes(habit.target)}`;
  return freq;
}
```

```tsx
export function ProgressRing({
  size, stroke, progress, color, children,
}: { size: number; stroke: number; progress: number; color: string; children?: React.ReactNode }) {
  const clamped = Math.max(0, Math.min(1, progress));
  const radius = (size - stroke) / 2;
  const circumference = 2 * Math.PI * radius;
  return (
    <div className="relative grid place-items-center" style={{ width: size, height: size }}>
      <svg width={size} height={size} className="-rotate-90" aria-hidden>
        <circle cx={size / 2} cy={size / 2} r={radius} fill="none"
                stroke="rgba(255,255,255,0.35)" strokeWidth={stroke} />
        <circle data-progress cx={size / 2} cy={size / 2} r={radius} fill="none"
                stroke={color} strokeWidth={stroke} strokeLinecap="round"
                strokeDasharray={circumference}
                strokeDashoffset={circumference * (1 - clamped)}
                style={{ transition: 'stroke-dashoffset 300ms ease' }} />
      </svg>
      {children != null && <div className="absolute grid place-items-center">{children}</div>}
    </div>
  );
}
```

```tsx
'use client';

import { Check, Minus, Plus } from 'lucide-react';
import { rgba } from '@/lib/colors';
import { nameIcon } from '@/lib/icons';
import { subtext } from '@/lib/labels';
import type { Habit } from '@/lib/types';
import { FlameBadge } from './FlameBadge';
import { ProgressRing } from './ProgressRing';

export interface HabitRowProps {
  habit: Habit;
  value: number;
  streak: number;
  onToggle: () => void;
  onStep: (delta: number) => void;
  onOpenTimer: () => void;
  onOpenValue: () => void;
}

/**
 * The row fill is the progress bar. `boolean` rows are always fully saturated
 * (the check carries the state) and progress rows keep a 55% floor so the white
 * text stays readable on a fresh, empty day — the ring and the x/y subtext are
 * the authoritative progress.
 */
export function HabitRow({
  habit, value, streak, onToggle, onStep, onOpenTimer, onOpenValue,
}: HabitRowProps) {
  const ratio = habit.target > 0 ? value / habit.target : 0;
  const fill = habit.type === 'boolean'
    ? (value > 0 ? 1 : 0)
    : Math.max(0.55, Math.min(1, ratio));
  const done = habit.type === 'boolean' ? value > 0 : ratio >= 1;
  const Icon = nameIcon(habit.icon);

  return (
    <li className="relative isolate overflow-hidden rounded-3xl"
        style={{ background: rgba(habit.color, 0.2) }}>
      <div data-testid="habit-fill"
           className="absolute inset-y-0 left-0"
           style={{ width: `${fill * 100}%`, background: habit.color, transition: 'width 300ms ease' }} />
      <div className="relative flex items-center gap-3 px-3 py-2.5">
        <span className="grid h-10 w-10 shrink-0 place-items-center rounded-full bg-white/25">
          <Icon size={20} color="#fff" />
        </span>

        <div className="min-w-0 flex-1">
          <p className="truncate text-sm font-bold text-white drop-shadow-sm">{habit.name}</p>
          <p className="truncate text-xs text-white/90 drop-shadow-sm">{subtext(habit, value)}</p>
        </div>

        <FlameBadge count={streak} className="absolute right-3 top-1.5 text-white" />

        {habit.type === 'boolean' && (
          <button type="button"
                  aria-label={done ? `Mark ${habit.name} not done` : `Mark ${habit.name} done`}
                  onClick={onToggle}
                  className="grid h-10 w-10 shrink-0 place-items-center rounded-full bg-white shadow">
            {done ? <Check size={22} color={habit.color} strokeWidth={3} /> : <span className="text-slate-400">○</span>}
          </button>
        )}

        {habit.type === 'quantity' && (
          <div className="flex shrink-0 items-center gap-1.5">
            <button type="button" aria-label={`Remove one ${habit.unit || 'unit'}`}
                    onClick={() => onStep(-1)}
                    className="grid h-8 w-8 place-items-center rounded-full bg-white/85">
              <Minus size={16} color={habit.color} />
            </button>
            <button type="button" aria-label={`Add one ${habit.unit || 'unit'}`}
                    onClick={() => onStep(1)}
                    className="grid h-10 w-10 place-items-center rounded-full bg-white shadow">
              <Plus size={20} color={habit.color} />
            </button>
          </div>
        )}

        {habit.type === 'timer' && (
          <button type="button" aria-label={`Open timer for ${habit.name}`} onClick={onOpenTimer}

            <ProgressRing size={40} stroke={4} progress={ratio} color={habit.color}>

            </ProgressRing>
          </button>

            </ProgressRing>
          </button>
        )}
      </div>
    </li>
  );
}
```

```tsx
'use client';

import { useEffect, useState } from 'react';
import type { Habit } from '@/lib/types';
import { Sheet } from './Sheet';

export function ValueSheet({
  habit, value, open, onSave, onClose,
}: { habit: Habit; value: number; open: boolean; onSave: (v: number) => void; onClose: () => void }) {
  const [draft, setDraft] = useState(String(value));

  useEffect(() => { if (open) setDraft(String(value)); }, [open, value]);

  const save = () => {
    const parsed = Number(draft);
    if (Number.isFinite(parsed) && parsed >= 0) onSave(Math.floor(parsed));
    onClose();
  };

  return (
    <Sheet open={open} onClose={onClose} title={habit.name}>
      <label className="mb-3 block text-sm text-[var(--color-subtle)]">
        {habit.unit ? `Amount (${habit.unit})` : 'Amount'}
        <input
          type="number" inputMode="numeric" min={0} value={draft}
          onChange={(e) => setDraft(e.target.value)}
          onKeyDown={(e) => { if (e.key === 'Enter') save(); }}
          className="mt-1 w-full rounded-xl border border-[var(--color-line)] bg-transparent px-3 py-2 text-base outline-none focus:border-[var(--color-accent)]"
        />
      </label>
      <button type="button" onClick={save}
              className="w-full rounded-2xl bg-[var(--color-accent)] px-4 py-3 font-semibold text-white">
        Save
      </button>
    </Sheet>
  );
}
```

```tsx
export function DateStrip({
  selected, today, onSelect,

      {days.map((key, index) => {

          <div key={key} className="relative flex flex-1 flex-col items-center gap-1">

              <span aria-hidden

                    style={{ width: '100%' }} />
            )}
            <span className={`text-[11px] ${isSelected ? 'font-bold text-[var(--color-fg)]' : 'text-[var(--color-subtle)]'}`}>
              {formatWeekday(key)}
            </span>
            <button
              type="button"
              disabled={disabled}
              aria-current={isSelected ? 'date' : undefined}
              aria-label={key}
```

```ts
// src/lib/streaks.ts
import { addDays, weekdayIndex } from './dates';
import { isCompleted } from './stats';
import type { Entry, Habit } from './types';

/**
 * Consecutive scheduled-and-completed days for each habit, walking back from
 * `today`. Unscheduled days are skipped (they neither count nor break); an
 * incomplete `today` does not break yesterday's streak.
 */
export function habitStreaks(
  habits: Habit[],
  entries: Entry[],
  today: string,
): Record<string, number> {
  const values = new Map(entries.map((e) => [`${e.habitId}|${e.date}`, e.value]));
  const streaks: Record<string, number> = {};

  for (const habit of habits) {
    const scheduledOn = (date: string) => habit.frequency.includes(weekdayIndex(date));
    const completedOn = (date: string) => isCompleted(habit, values.get(`${habit.id}|${date}`) ?? 0);

    let cursor = today;
    let streak = 0;

    // Today only extends the streak; it never breaks it.
    if (scheduledOn(cursor) && completedOn(cursor)) streak = 1;
    cursor = addDays(cursor, -1);

    for (let guard = 0; guard < 370; guard++, cursor = addDays(cursor, -1)) {
      if (!scheduledOn(cursor)) continue;   // unscheduled: neither counts nor breaks
      if (!completedOn(cursor)) break;      // a missed scheduled day ends the run
      streak++;
    }
    streaks[habit.id] = streak;
  }
  return streaks;
}
```

```tsx
// src/components/TodayScreen.tsx
'use client';

import { Flame, Plus } from 'lucide-react';
import { useRouter } from 'next/navigation';
import { useCallback, useEffect, useMemo, useState } from 'react';
import { addDays, classifyDate, formatLong, todayKey } from '@/lib/dates';
import { loadRange, listHabits, putEntry } from '@/lib/repo';
import { buildDayStats, currentStreak } from '@/lib/stats';
import { habitStreaks } from '@/lib/streaks';
import { useLiveQuery } from '@/lib/useLiveQuery';
import type { Habit } from '@/lib/types';
import { CategorySection } from './CategorySection';
import { DateStrip } from './DateStrip';
import { ValueSheet } from './ValueSheet';

const STORE_KEY = 'habibit:collapsed';
const readCollapsed = (): Record<string, boolean> => {
  try { return JSON.parse(localStorage.getItem(STORE_KEY) ?? '{}'); } catch { return {}; }
};

export function TodayScreen({ date }: { date: string }) {
  const [collapsed, setCollapsed] = useState<Record<string, boolean>>({});
  const [valueSheet, setValueSheet] = useState<Habit | null>(null);
  const router = useRouter();
  const today = todayKey();

  // One-time client hydration of the collapse state (localStorage is not SSR-safe).
  useEffect(() => { setCollapsed(readCollapsed()); }, []);

  const habits = useLiveQuery(() => listHabits(), []);
  // A 40-day window so per-habit streaks and the header flame come from real
  // history; the visible day's values are filtered out of it below.
  const rangeStart = addDays(date, -40);
  const entries = useLiveQuery(() => loadRange(rangeStart, date), [rangeStart, date]);
  const groups = useMemo(() => {
    const list = habits ?? [];
    const map = new Map<string, Habit[]>();
    for (const habit of list) {
      if (!habit.frequency.includes(new Date(`${date}T12:00:00`).getDay())) continue;
      const bucket = map.get(habit.category) ?? [];
      bucket.push(habit);
      map.set(habit.category, bucket);
    }
    return [...map.entries()].sort(([a], [b]) => a.localeCompare(b));
  }, [habits, date]);

  const values = useMemo(() => {
    const map: Record<string, number> = {};
    for (const entry of entries ?? []) if (entry.date === date) map[entry.habitId] = entry.value;
    return map;
  }, [entries, date]);

  const streaks = useMemo(
    () => habitStreaks(habits ?? [], entries ?? [], date),
    [habits, entries, date],
  );

  const overallStreak = useMemo(() => {
    if (!habits || !entries) return 0;
    const stats = buildDayStats(habits, entries, { from: addDays(date, -40), to: date });
    return currentStreak(stats, date);
  }, [habits, entries, date]);

  const setValue = useCallback(async (habit: Habit, value: number) => {
    await putEntry(habit.id, date, Math.max(0, value));
  }, [date]);

  const toggle = useCallback((habit: Habit) => {
    void setValue(habit, (values[habit.id] ?? 0) > 0 ? 0 : (habit.type === 'boolean' ? 1 : habit.target));
  }, [setValue, values]);

  const step = useCallback((habit: Habit, delta: number) => {
    void setValue(habit, (values[habit.id] ?? 0) + delta);
  }, [setValue, values]);

  const toggleCollapse = useCallback((category: string) => {
    setCollapsed((prev) => {
      const next = { ...prev, [category]: !prev[category] };
      try { localStorage.setItem(STORE_KEY, JSON.stringify(next)); } catch { /* private mode */ }
      return next;
    });
  }, []);

  const isFuture = classifyDate(date, today) === 'future';
  const isPast = classifyDate(date, today) === 'past';

  return (
    <div className="mx-auto w-full max-w-3xl px-2 sm:px-4">
      <header className="flex items-center justify-between gap-3 px-2 py-4">
        <h1 className="text-lg font-extrabold">{isPast ? formatLong(date) : 'Today'}</h1>
        <div className="flex items-center gap-3">
          <span className="flex items-center gap-1 text-sm font-bold">
            <Flame size={18} className="text-[#f97316]" fill="#f97316" /> {overallStreak}
          </span>
          <button type="button" aria-label="Add habit" onClick={() => router.push('/settings')}
                  className="grid h-9 w-9 place-items-center rounded-full bg-[var(--color-muted)]">
            <Plus size={18} />
          </button>
        </div>
      </header>

      <DateStrip selected={date} today={today}
                 onSelect={(key) => router.push(key === today ? '/today' : `/today/${key}`)} />

      {habits === undefined ? (
        <p className="p-6 text-center text-sm text-[var(--color-subtle)]">Loading…</p>
      ) : habits.length === 0 ? (
        <div className="p-10 text-center">
          <p className="mb-3 text-base font-semibold">Create your first habit</p>
          <a href="/settings" className="rounded-2xl bg-[var(--color-accent)] px-4 py-2.5 text-sm font-semibold text-white">
            Add a habit
          </a>
        </div>
      ) : isFuture ? (
        <p className="p-6 text-center text-sm text-[var(--color-subtle)]">That day hasn’t happened yet.</p>
      ) : groups.length === 0 ? (
        <p className="p-6 text-center text-sm text-[var(--color-subtle)]">Nothing scheduled on this day.</p>
      ) : (
        <div className="grid gap-3 md:grid-cols-2 xl:grid-cols-3">
          {groups.map(([category, list]) => (
            <CategorySection
              key={category}
              category={category}
              habits={list}
              collapsed={collapsed[category] ?? false}
              onToggleCollapse={() => toggleCollapse(category)}
              values={values}
              streaks={streaks}
              onToggle={toggle}
              onStep={step}
              onOpenTimer={() => { /* wired to TimerModal in Task 9 */ }}
              onOpenValue={setValueSheet}
            />
          ))}
        </div>
      )}

      {valueSheet && (
        <ValueSheet
          habit={valueSheet}
          value={values[valueSheet.id] ?? 0}
          open
          onSave={(v) => void setValue(valueSheet, v)}
          onClose={() => setValueSheet(null)}
        />
      )}
    </div>
  );
}
```

```tsx
// src/components/TimerModal.tsx
'use client';

import { Pause, Play, Plus, Minus, RotateCcw, SkipForward, Undo2 } from 'lucide-react';
import { useEffect, useRef, useState } from 'react';
import { putEntry } from '@/lib/repo';
import type { Habit } from '@/lib/types';
import { FlameBadge } from './FlameBadge';
import { Sheet } from './Sheet';

function clock(total: number): string {
  const remaining = Math.max(0, total);
  const m = Math.floor(remaining / 60);
  const s = remaining % 60;
  return `${String(m).padStart(2, '0')}:${String(s).padStart(2, '0')}`;
}

export function TimerModal({
  habit, initialSeconds, streak, date, onClose, onComplete,
}: {
  habit: Habit;
  initialSeconds: number;
  streak: number;
  date: string;
  onClose: () => void;
  onComplete: () => void;
}) {
  const [duration, setDuration] = useState(habit.target || 600);
  const [elapsed, setElapsed] = useState(initialSeconds);
  const [running, setRunning] = useState(false);
  const completed = useRef(false);

  // The app's only setInterval: created when running, always cleared on
  // unmount or when `running`/`duration` change.
  useEffect(() => {
    if (!running) return;
    const id = window.setInterval(() => {
      setElapsed((e) => Math.min(e + 1, duration));
    }, 1000);
    return () => window.clearInterval(id);
  }, [running, duration]);

  useEffect(() => {
    if (!running || completed.current || elapsed < duration) return;
    completed.current = true;
    setRunning(false);
    void putEntry(habit.id, date, duration);   // value = seconds done = target
    onComplete();
  }, [elapsed, duration, running, habit.id, date, onComplete]);

  const remaining = Math.max(0, duration - elapsed);
  const ratio = duration > 0 ? elapsed / duration : 0;

  return (
    <Sheet open onClose={onClose} title={habit.name} dark>
      <p className="mb-4 text-center text-xs text-white/60">{habit.name} timer</p>

      <div className="relative mx-auto grid h-56 w-56 place-items-center">
        <div className="absolute inset-0 rounded-full"
             style={{ background: `conic-gradient(${habit.color} ${ratio * 360}deg, #2a2a33 0deg)` }} />
        <div className="absolute inset-3 rounded-full bg-[#111116]" />
        <div className="relative text-center">
          <FlameBadge count={streak} className="justify-center text-white/80" />
          <p className="text-4xl font-bold tabular-nums text-white">{clock(remaining)}</p>
        </div>
      </div>

      <div className="mt-4 flex items-center justify-center gap-6">
        <button type="button" aria-label="Decrease duration"
                onClick={() => setDuration((d) => Math.max(60, d - 60))}
                className="grid h-11 w-11 place-items-center rounded-full bg-white/10 text-white">
          <Minus size={18} />
        </button>
        <button type="button" aria-label="Increase duration"
                onClick={() => setDuration((d) => d + 60)}
                className="grid h-11 w-11 place-items-center rounded-full bg-white/10 text-white">
          <Plus size={18} />
        </button>
      </div>

      <div className="mt-4 flex items-center gap-2">
        <button type="button" aria-label="Skip" onClick={() => { setRunning(false); onClose(); }}
                className="grid h-10 w-10 place-items-center rounded-full bg-white/10 text-white">
          <SkipForward size={16} />
        </button>
        <button type="button" aria-label="Undo minute" onClick={() => setElapsed((e) => Math.max(0, e - 60))}
                className="grid h-10 w-10 place-items-center rounded-full bg-white/10 text-white">
          <Undo2 size={16} />
        </button>
        <button type="button" aria-label="Reset timer"
                onClick={() => { setElapsed(0); completed.current = false; }}
                className="grid h-10 w-10 place-items-center rounded-full bg-white/10 text-white">
          <RotateCcw size={16} />
        </button>
        <button type="button" onClick={() => setDuration((d) => d + 300)}
                className="flex-1 rounded-full px-4 py-2.5 text-sm font-bold text-white"
                style={{ background: habit.color }}>
          +5 minutes
        </button>
      </div>

      <button
        type="button"
        onClick={() => setRunning((r) => !r)}
        className="mt-3 flex w-full items-center justify-center gap-2 rounded-full py-3.5 font-bold text-white"
        style={{ background: habit.color }}
      >
        {running ? <Pause size={18} /> : <Play size={18} />}
        {running ? 'Pause' : 'Start timer'}
      </button>
    </Sheet>
  );
}
```

```tsx
  currentStreak, longestStreak, perIntentionTotals, sumCompletions,

import { useLiveQuery } from '@/lib/useLiveQuery';
import { IntentionBar } from './IntentionBar';
import { StatTile } from './StatTile';
import { YearNav } from './YearNav';

export function StatsScreen() {
  const today = todayKey();
  const maxYear = Number(today.slice(0, 4));
  const [year, setYear] = useState(maxYear);
  const [minYear, setMinYear] = useState(maxYear - 1);

  const habits = useLiveQuery(() => listHabits(), []);
  const entries = useLiveQuery(
    () => loadRange(`${year}-01-01`, `${year}-12-31`),
    [year],
  );
  // A separate, year-independent query so the all-time tiles are not limited
  // to whichever year is selected.
  const allEntries = useLiveQuery(
    () => loadRange(`${minYear}-01-01`, today),
    [minYear, today],
  );

  useEffect(() => {
    if (!habits?.length) return;
    const earliest = new Date(Math.min(...habits.map((h) => h.createdAt))).getFullYear();
    setMinYear(Math.min(earliest, maxYear));
  }, [habits, maxYear]);

  const stats = useMemo(
    () => buildDayStats(habits ?? [], entries ?? [], {
      from: `${year}-01-01`,
      to: year === maxYear ? today : `${year}-12-31`,

  );

    () => buildDayStats(habits ?? [], allEntries ?? [], { from: `${minYear}-01-01`, to: today }),
    [habits, allEntries, minYear, today],
  );
```

```tsx
// src/components/Heatmap.tsx
'use client';

import { useEffect, useMemo, useState } from 'react';
import { useRouter } from 'next/navigation';
import { formatShort } from '@/lib/dates';
import { monthLabelPositions } from '@/lib/dates';
import { heatmapCells, type HeatCell } from '@/lib/stats';
import type { Entry, Habit } from '@/lib/types';

const WEEKDAYS = ['Mon', 'Wed', 'Fri'];
const MONTHS = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec'];
const CELL = 13;   // px, gap handled by the grid gap
const GAP = 3;

export function Heatmap({
  year, habits, entries, today, compact = false,
}: {
  year: number;
  habits: Habit[];
  entries: Entry[];
  today: string;
  compact?: boolean;
}) {
  const router = useRouter();
  const cells = useMemo(() => heatmapCells(year, habits, entries, today), [year, habits, entries, today]);
  const months = useMemo(() => monthLabelPositions(year), [year]);
  const weeks = cells.length / 7;

  const [hover, setHover] = useState<HeatCell | null>(null);
  const [pinned, setPinned] = useState<HeatCell | null>(null);
  const tooltip = pinned ?? hover;

  useEffect(() => {
    if (!pinned) return;
    const onKey = (e: KeyboardEvent) => { if (e.key === 'Escape') setPinned(null); };
    document.addEventListener('keydown', onKey);
    return () => document.removeEventListener('keydown', onKey);
  }, [pinned]);

  const visibleCells = compact ? cells.slice(Math.max(0, cells.length - 26 * 7)) : cells;
  const columnCount = visibleCells.length / 7;

  const open = (cell: HeatCell) => {
    if (hover?.date === cell.date || pinned?.date === cell.date) {
      setPinned(null);
      router.push(`/today/${cell.date}`);
    } else {
      setPinned(cell);
    }
  };

  return (
    <section className="mt-6 rounded-2xl bg-[var(--color-panel)] p-4" aria-label="Activity heatmap">
      <div className="relative">
        {tooltip && (
          <div data-testid="hm-tooltip"
               className="absolute -top-2 left-1/2 z-20 w-56 -translate-x-1/2 -translate-y-full rounded-xl border border-[var(--color-line)] bg-[var(--color-bg)] px-3 py-2 text-xs shadow-lg">
            <p className="font-bold">{formatShort(tooltip.date)}, {tooltip.date.slice(0, 4)}</p>
            <p className="text-[var(--color-subtle)]">
              {tooltip.completed} of {tooltip.scheduled} completed
            </p>
            <p className="text-[var(--color-subtle)]">
              {tooltip.scheduled ? Math.round((tooltip.completed / tooltip.scheduled) * 100) : 0}%
            </p>
          </div>
        )}

        <div className="flex gap-1.5">
          <div className="flex w-8 shrink-0 flex-col justify-between py-0.5 text-[9px] text-[var(--color-subtle)]">
            {WEEKDAYS.map((d) => <span key={d}>{d}</span>)}
          </div>

          <div className="min-w-0 flex-1 overflow-x-auto pb-1">
            <div style={{ width: columnCount * (CELL + GAP) }}>
              {/* Month labels */}
              <div className="relative mb-1 h-3 text-[9px] text-[var(--color-subtle)]">
                {months.map(({ month, column }) => (
                  <span key={month} className="absolute"
                        style={{ left: column * (CELL + GAP), visibility: column >= columnCount ? 'hidden' : 'visible' }}>
                    {MONTHS[month]}
                  </span>
                ))}
              </div>

              {/* 7 weekday rows × week columns */}
              <div className="grid grid-flow-col grid-rows-7 gap-[3px]"
                   style={{ gridAutoColumns: CELL }}>
                {visibleCells.map((cell) => (
                  <button
                    key={cell.date}
                    type="button"
                    data-testid={`hm-cell-${cell.date}`}
                    aria-label={`${cell.date}: ${cell.completed} of ${cell.scheduled} completed`}
                    onMouseEnter={(e) => { if (e.nativeEvent.pointerType !== 'touch') setHover(cell); }}
                    onMouseLeave={() => setHover(null)}
                    onClick={() => open(cell)}
                    className="h-[13px] w-[13px] rounded-[3px]"
                    style={{
                      background: cell.inYear && !cell.future
                        ? `var(--hm-${cell.level})`
                        : 'var(--hm-empty)',
                      outline: tooltip?.date === cell.date ? '1px solid var(--color-fg)' : 'none',
                    }}
                  />
                ))}
              </div>
            </div>
          </div>
        </div>
      </div>

      <div data-testid="hm-legend" className="mt-3 flex items-center justify-end gap-1 text-[10px] text-[var(--color-subtle)]">
        <span className="mr-1">Less</span>
        {[0, 1, 2, 3, 4].map((level) => (
          <span key={level} data-level={level} className="h-[10px] w-[10px] rounded-[2px]"
                style={{ background: `var(--hm-${level})` }} />
        ))}
        <span className="ml-1">More</span>
      </div>
    </section>
  );
}
```

```tsx
'use client';

import { Share2 } from 'lucide-react';
import { useMemo } from 'react';
import { formatLong, todayKey } from '@/lib/dates';
import { listHabits, loadRange, putEntry } from '@/lib/repo';
import { isCompleted } from '@/lib/stats';
import { intentionColor } from '@/lib/colors';
import { intentionIcon } from '@/lib/icons';
import { quoteFor } from '@/lib/quotes';
import { useLiveQuery } from '@/lib/useLiveQuery';
import type { Habit } from '@/lib/types';
import { Heatmap } from './Heatmap';

export function NoteScreen({ date }: { date: string }) {
  const habits = useLiveQuery(() => listHabits(), []);
  const entries = useLiveQuery(() => loadRange(date, date), [date]);
  const quote = useMemo(() => quoteFor(date), [date]);
  const today = todayKey();
  const year = Number(date.slice(0, 4));

  const values = useMemo(() => {
    const map: Record<string, number> = {};
    for (const entry of entries ?? []) map[entry.habitId] = entry.value;
    return map;
  }, [entries]);

  const groups = useMemo(() => {
    const map = new Map<string, Habit[]>();
    for (const habit of habits ?? []) {
      const bucket = map.get(habit.intention) ?? [];
      bucket.push(habit);
      map.set(habit.intention, bucket);
    }
    return [...map.entries()];
  }, [habits]);

  const share = async () => {
    const url = `${window.location.origin}/today/${date}`;
    if (navigator.share) { try { await navigator.share({ title: 'Habibit', url }); return; } catch { /* dismissed */ } }
    await navigator.clipboard?.writeText(url);
  };

  return (
    <div className="mx-auto w-full max-w-3xl px-4 pb-10">
      <header className="flex items-center justify-between py-4">
        <h1 className="text-lg font-extrabold">{formatLong(date)}</h1>
        <button type="button" aria-label="Share this day" onClick={() => void share()}
                className="grid h-9 w-9 place-items-center rounded-full bg-[var(--color-muted)]">
          <Share2 size={16} />
        </button>
      </header>

      <blockquote className="mb-5 rounded-2xl bg-[var(--color-panel)] px-4 py-3 text-sm italic">
        “{quote.text}” <span className="not-italic text-[var(--color-subtle)]">— {quote.author}</span>
      </blockquote>

      <Heatmap year={year} habits={habits ?? []} entries={entries ?? []} today={today} compact />

      <div className="mt-5 flex flex-col gap-3">
        {groups.map(([intention, list]) => {
          const color = intentionColor(intention);
          const Icon = intentionIcon(list);
          return (
            <section key={intention} className="rounded-3xl p-4" style={{ background: color }}>
              <h2 className="mb-2 flex items-center gap-2 text-sm font-extrabold uppercase tracking-wide text-white">
                <Icon size={16} /> {intention.toUpperCase()}
              </h2>
              <ul className="flex flex-col gap-2">

                    </li>
                  );
                })}
              </ul>
            </section>
          );
        })}
      </div>
    </div>
  );
```

```tsx
// src/components/HabitForm.tsx
'use client';

import { useEffect, useState } from 'react';
import { HABIT_COLORS, intentionColor } from '@/lib/colors';
import { ICON_CHOICES, nameIcon } from '@/lib/icons';
import type { Habit, HabitType } from '@/lib/types';
import { Combobox } from './Combobox';
import { Sheet } from './Sheet';

const DAYS = ['Sun', 'Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat'] as const;
const TYPES: HabitType[] = ['boolean', 'quantity', 'timer'];

export function HabitForm({
  habit, open, categories = [], intentions = [], onSave, onClose,
}: {
  habit: Habit;
  open: boolean;
  categories?: string[];
  intentions?: string[];
  onSave: (h: Habit) => void;
  onClose: () => void;
}) {

  useEffect(() => { setDraft(habit); }, [habit]);

      draft.type === 'boolean' ? 1

      : Math.max(1, Math.round(Number(draft.target) || 1));

    onClose();
```

```tsx
// src/components/HabitList.tsx
'use client';

import { GripVertical, Pencil, Trash2 } from 'lucide-react';
import { useState } from 'react';
import { categoryIcon, nameIcon } from '@/lib/icons';
import { frequencyLabel } from '@/lib/labels';
import type { Habit } from '@/lib/types';

export function HabitList({
  habits, onEdit, onDelete, onReorder,
}: {
  habits: Habit[];
  onEdit: (id: string) => void;
  onDelete: (id: string) => void;
  onReorder: (habits: Habit[]) => void;
}) {
  const [pendingDelete, setPendingDelete] = useState<string | null>(null);
  const [dragId, setDragId] = useState<string | null>(null);

  const categories = [...new Set(habits.map((h) => h.category))].sort();

  const drop = (target: Habit) => {
    if (!dragId || dragId === target.id) return;
    const source = habits.find((h) => h.id === dragId);
    if (!source || source.category !== target.category) return;   // reorder within a category only
    const siblings = habits.filter((h) => h.category === target.category)
      .sort((a, b) => a.order - b.order);
    const from = siblings.findIndex((h) => h.id === dragId);
    const to = siblings.findIndex((h) => h.id === target.id);
    const next = [...siblings];
    next.splice(to, 0, next.splice(from, 1)[0]);
    const reordered = next.map((h, index) => ({ ...h, order: index }));
    onReorder([
      ...habits.filter((h) => h.category !== target.category),
      ...reordered,
    ]);
    setDragId(null);
  };

  return (
    <div className="flex flex-col gap-4">
      {categories.map((category) => {
        const Icon = categoryIcon(category);
        const list = habits.filter((h) => h.category === category).sort((a, b) => a.order - b.order);
        return (
          <section key={category}>
            <h3 className="mb-1.5 flex items-center gap-2 text-xs font-bold uppercase tracking-widest text-[var(--color-subtle)]">
              <Icon size={14} /> {category}
            </h3>
            <ul className="flex flex-col gap-2">
              {list.map((habit) => {
                const HabitIcon = nameIcon(habit.icon);
                return (
                  <li key={habit.id} data-testid={`habit-row-${habit.id}`} draggable
                      onDragStart={() => setDragId(habit.id)}
                      onDragOver={(e) => e.preventDefault()}
                      onDrop={() => drop(habit)}
                      className="flex items-center gap-3 rounded-2xl border border-[var(--color-line)] bg-[var(--color-panel)] px-3 py-2.5">
                    <GripVertical size={16} className="cursor-grab text-[var(--color-subtle)]" />
                    <span className="grid h-8 w-8 place-items-center rounded-full" style={{ background: habit.color }}>
                      <HabitIcon size={16} color="#fff" />
                    </span>
                    <div className="min-w-0 flex-1">
                      <p className="truncate text-sm font-semibold">{habit.name}</p>
                      <p className="truncate text-xs text-[var(--color-subtle)]">
                        {habit.intention} · {frequencyLabel(habit.frequency)}
                      </p>
                    </div>
                    <button type="button" aria-label={`Edit ${habit.name}`} onClick={() => onEdit(habit.id)}
                            className="grid h-8 w-8 place-items-center rounded-full hover:bg-[var(--color-muted)]">
                      <Pencil size={15} />
                    </button>
                    <button type="button" aria-label={`Delete ${habit.name}`} onClick={() => setPendingDelete(habit.id)}
                            className="grid h-8 w-8 place-items-center rounded-full text-red-500 hover:bg-red-500/10">
                      <Trash2 size={15} />
                    </button>
                  </li>
                );
              })}
            </ul>
          </section>
        );
      })}

      {pendingDelete && (
        <div className="rounded-2xl border border-red-300 bg-red-50 p-4 text-sm dark:border-red-900 dark:bg-red-950">
          <p className="mb-2 font-semibold">Delete “{habits.find((h) => h.id === pendingDelete)?.name}” and all of its history?</p>
          <div className="flex gap-2">
            <button type="button" onClick={() => setPendingDelete(null)}
                    className="rounded-xl border border-[var(--color-line)] px-3 py-1.5">Cancel</button>
            <button type="button" onClick={() => { onDelete(pendingDelete); setPendingDelete(null); }}
                    className="rounded-xl bg-red-600 px-3 py-1.5 font-semibold text-white">Yes, delete</button>
          </div>
        </div>
      )}
    </div>
  );
}
```

```tsx
// src/components/HabitsPanel.tsx
'use client';

import { Plus } from 'lucide-react';
import { useCallback, useMemo, useState } from 'react';
import { deleteHabit, listHabits, newId, putHabit } from '@/lib/repo';
import { useLiveQuery } from '@/lib/useLiveQuery';
import type { Habit } from '@/lib/types';
import { HabitForm } from './HabitForm';
import { HabitList } from './HabitList';

const blank = (): Habit => ({
  id: newId(), name: '', icon: 'target', color: '#6366f1', category: 'Morning',
  intention: '', type: 'boolean', target: 1, unit: '',
  frequency: [0, 1, 2, 3, 4, 5, 6], order: 0, createdAt: Date.now(),
});

export function HabitsPanel() {
  const habits = useLiveQuery(() => listHabits(), []);
  const [editing, setEditing] = useState<Habit | null>(null);

  const categories = useMemo(
    () => [...new Set((habits ?? []).map((h) => h.category))].sort(),
    [habits],
  );
  const intentions = useMemo(
    () => [...new Set((habits ?? []).map((h) => h.intention).filter(Boolean))].sort(),
    [habits],
  );

  const save = useCallback(async (habit: Habit) => {
    await putHabit(habit);
    setEditing(null);
  }, []);

  return (
    <section>
      <div className="mb-3 flex items-center justify-between">
        <h2 className="text-xs font-bold uppercase tracking-widest text-[var(--color-subtle)]">Habits</h2>
        <button type="button" onClick={() => setEditing(blank())}
                className="flex items-center gap-1.5 rounded-full bg-[var(--color-accent)] px-3 py-1.5 text-sm font-semibold text-white">
          <Plus size={15} /> New habit
        </button>
      </div>

      <HabitList
        habits={habits ?? []}
        onEdit={(id) => setEditing((habits ?? []).find((h) => h.id === id) ?? null)}
        onDelete={(id) => void deleteHabit(id)}
        onReorder={(next) => { for (const habit of next) void putHabit(habit); }}
      />

      {editing && (
        <HabitForm
          habit={editing} open categories={categories} intentions={intentions}
          onSave={(h) => void save(h)} onClose={() => setEditing(null)}
        />
      )}
    </section>
  );
}
```

```ts
// src/lib/theme.ts
'use client';

export type ThemePref = 'system' | 'light' | 'dark';
const KEY = 'habibit:theme';

function prefersDark(): boolean {
  return typeof window !== 'undefined' && window.matchMedia?.('(prefers-color-scheme: dark)').matches === true;
}

export function getThemePref(): ThemePref {
  try {
    const stored = localStorage.getItem(KEY);
    return stored === 'dark' || stored === 'light' || stored === 'system' ? stored : 'system';
  } catch {
    return 'system';
  }
}

export function applyTheme(pref: ThemePref): void {
  const dark = pref === 'dark' || (pref === 'system' && prefersDark());
  document.documentElement.dataset.theme = dark ? 'dark' : 'light';
  document.documentElement.dataset.themePref = pref;
  try { localStorage.setItem(KEY, pref); } catch { /* private mode: session only */ }
}
```

```tsx
// src/components/DataPanel.tsx
'use client';

import { Download, RotateCcw, Upload } from 'lucide-react';
import { useRef, useState } from 'react';
import { clearAll, exportState, importState } from '@/lib/repo';
import { seedIfEmpty } from '@/lib/seed';

export function DataPanel() {
  const fileRef = useRef<HTMLInputElement>(null);
  const [message, setMessage] = useState<{ kind: 'ok' | 'error'; text: string } | null>(null);
  const [confirmReset, setConfirmReset] = useState(false);

  const exportJson = async () => {
    const data = await exportState();
    const blob = new Blob([JSON.stringify(data, null, 2)], { type: 'application/json' });
    const url = URL.createObjectURL(blob);
    const a = document.createElement('a');
    a.href = url;
    a.download = `habibit-${new Date().toISOString().slice(0, 10)}.json`;
    a.click();
    URL.revokeObjectURL(url);
    setMessage({ kind: 'ok', text: 'Exported.' });
  };

  const importJson = async (file: File | undefined) => {
    if (!file) return;
    try {
      const text = await file.text();
      let parsed: unknown;
      try { parsed = JSON.parse(text); }
      catch { throw new Error('That file is not valid JSON.'); }
      await importState(parsed);          // validates fully before writing
      setMessage({ kind: 'ok', text: 'Imported.' });
    } catch (err) {
      setMessage({ kind: 'error', text: err instanceof Error ? err.message : 'Import failed.' });
    } finally {
      if (fileRef.current) fileRef.current.value = '';
    }
  };

  const reset = async () => {
    await clearAll();
    await seedIfEmpty();
    setConfirmReset(false);
    setMessage({ kind: 'ok', text: 'Reset and re-seeded.' });
  };

  return (
    <section className="mt-6">
      <h2 className="mb-2 text-xs font-bold uppercase tracking-widest text-[var(--color-subtle)]">Data</h2>

      <div className="flex flex-wrap gap-2">
        <button type="button" onClick={() => void exportJson()}
                className="flex items-center gap-2 rounded-2xl border border-[var(--color-line)] px-4 py-2.5 text-sm font-semibold">
          <Download size={15} /> Export JSON
        </button>

        <button type="button" onClick={() => fileRef.current?.click()}
                className="flex items-center gap-2 rounded-2xl border border-[var(--color-line)] px-4 py-2.5 text-sm font-semibold">
          <Upload size={15} /> Import JSON
        </button>
        <input ref={fileRef} type="file" accept="application/json" className="sr-only"
               aria-label="Import JSON file"
               onChange={(e) => void importJson(e.target.files?.[0])} />

        <button type="button" onClick={() => setConfirmReset(true)}
                className="flex items-center gap-2 rounded-2xl border border-red-300 px-4 py-2.5 text-sm font-semibold text-red-500">
          <RotateCcw size={15} /> Reset data
        </button>
      </div>

      {confirmReset && (
        <div className="mt-3 rounded-2xl border border-red-300 bg-red-50 p-4 text-sm dark:border-red-900 dark:bg-red-950">
          <p className="mb-2 font-semibold">Erase everything and restore the example habits?</p>
          <div className="flex gap-2">
            <button type="button" onClick={() => setConfirmReset(false)}
                    className="rounded-xl border border-[var(--color-line)] px-3 py-1.5">Cancel</button>
            <button type="button" onClick={() => void reset()}
                    className="rounded-xl bg-red-600 px-3 py-1.5 font-semibold text-white">Yes, reset</button>
          </div>
        </div>
      )}

      {message && (
        <p role={message.kind === 'error' ? 'alert' : 'status'}
           className={`mt-3 text-sm ${message.kind === 'error' ? 'text-red-500' : 'text-[var(--color-subtle)]'}`}>
          {message.text}
        </p>
      )}
    </section>
  );
}
```
